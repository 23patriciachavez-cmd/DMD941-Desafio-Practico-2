
# Desafío Práctico 2 — Cubo OLAP AdventureWorks

## Descripción
Proyecto académico de Datawarehouse y Minería de Datos.

Se restauró AdventureWorksDW2025 en SQL Server 2025,
se desarrolló un cubo OLAP multidimensional mediante
Visual Studio y SQL Server Analysis Services, y se
construyó un dashboard en Power BI con conexión en vivo.

## Herramientas
- SQL Server 2025
- SQL Server Management Studio
- SQL Server Analysis Services
- Visual Studio 2026
- Power BI Desktop
